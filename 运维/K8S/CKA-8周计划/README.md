## 使用方法

### 每周固定动作

1. **周一开始**：打开对应 Week 文件，通读「本周目标」，写进日历
2. **每天**：按「逐日安排」执行，**必须动手敲**，不能只看
3. **周末**：完成「动手实验」，对着「验收标准」逐条打勾
4. **周日晚上**：填「踩坑记录」和「复盘区」，没打勾的补上
5. **更新本文件的进度表**

### 三条原则

- **不敲不算学**：每个知识点都要在真实集群上跑一遍
- **不勾不算完**：验收标准有一条没过，就不算学完这周
- **踩坑记录最值钱**：报错、原因、解决方式——考前只看这个和速查表

### 时间不够怎么办

看 [../CKA大纲与学习路线.md](../CKA大纲与学习路线.md) 的「时间紧张版（4 周冲刺）」章节。

优先级建议（时间紧时按这个顺序砍）：

```
W7 排障（30%）> W6 etcd/RBAC > W3 Taint > W4 NetworkPolicy > 其他
```
